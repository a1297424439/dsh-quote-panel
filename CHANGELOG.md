# Changelog

## 1.0.0 (2026-08-19)

- Initial open-source release.
- A-share default page: Shanghai Composite / Shenzhen Component / ChiNext.
- US default page: Dow Jones / Nasdaq Composite / S&P 500.
- A-share K-lines: intraday (分时), 60-min, daily, weekly, monthly.
- US K-lines: daily, weekly, monthly.
- Per-market watchlist with add/remove, persisted in localStorage.
- Auto-refresh quotes (5 s CN / 10 s US).
- Always-on-top, draggable panel with position memory.
- Zero-config free data sources (Tencent Finance).
